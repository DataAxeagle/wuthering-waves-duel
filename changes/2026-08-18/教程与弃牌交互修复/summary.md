# 教程与弃牌交互修复

- 新手教程改为玩家固定先攻，并加入全局暗幕与当前操作高亮。
- 准备阶段换牌可显示已选卡牌与数量，并在确认后执行等量替换。
- 效果要求弃牌时，改为中央弹窗选择并确认弃置。
- “抽后弃牌”会先停留在弃牌待处理阶段，确认弃牌后才推进至下一回合；测试场与正式对局共用此流程。
- 双方蓝色对抗视为双方各自完成蓝色判定：双方的抽牌/弃牌效果按顺序全部结算，不再被后一个效果覆盖。
- 对抗和连击后不再立即切换回合：所有效果结算后，回合方进入仅可结束回合的收尾状态；AI 按同样规则收尾后自动结束。
- 效果弃牌弹窗改为居中显示，确认弃牌按钮固定在卡牌选择区下方；修复按钮 CSS 隐藏状态未解除而无法点击的问题。
- 弃牌选择卡增加“已选择”角标和实时计数；测试场双方后续抽牌改为各自选择的同一张实体卡并保留卡面。
- 右侧收尾阶段状态改为“等待结束回合”，教程与 AI 状态描述同步采用手动收尾流程。
- 新手引导按当前操作高亮手牌、角色、按钮与场地区域；其余区域由暗幕压低亮度。
- 教学动画播放时临时恢复全局亮度；响应盖牌改为与弃牌一致的居中选择弹窗，所有卡牌选择统一黄色外框。
- 修复教程聚焦层级：手牌、牌库等带独立叠放层级的区域会连同父容器抬至暗幕上方，蓝框内内容保持正常亮度；执行动画和阶段总结期间撤去暗幕与高亮，恢复全局亮度。
- 教程操作改为逐步聚焦：充能依次高亮“充能”按钮、手牌、中央确认框；升级依次高亮“升级”按钮、角色区、手牌、中央确认框；战斗同样按按钮、手牌、确认框推进，并随当前子步骤更新提示文字。
- 修复中央确认弹窗被教程高亮样式改为普通文档流定位的问题：弹窗在被蓝框标注时仍固定居中，不会因选牌而下移。
- 追击教学改为条件分支：只有本局战斗实际使我方获得追击权时，才在战斗结算后引导选择红色连击或停止追击；停止后继续进入手动结束回合教学。
- 场地导览改为五步逐项说明：协奏区、角色牌库、牌库与弃牌区、主要阶段区、当前选择区。每步仅高亮当前区域、其余区域变暗，并在中央弹窗点击“下一步”切换。
- 删除结束回合教学：普通战斗结算后立即进入场地导览；如触发追击，则追击教学结束后立即进入场地导览。导览蓝框改为独立固定定位框，按当前说明重新测量目标位置，不会遗留上一阶段按钮高亮。
- 修复独立定位框在部分 Windows 缩放环境中产生坐标错位的问题：取消该定位层，蓝框直接绘制在当前导览的真实元素上，保证说明“角色牌库”只标记角色牌库。
- 修复男漂共鸣技卡面绑定：`SD02-020 感知` 使用 `SD02-021` 卡面，`SD02-021 钩索` 使用 `SD02-020` 卡面；卡牌名称、数值与规则文本保持原样。
- 导览高亮在真实目标元素上追加蓝色描边与光晕，目标所在容器抬至暗幕上层，保证框内保持正常亮度。主界面固定隐藏“返回当前对局”；战斗内暂停菜单保留该选项，“返回主界面”会放弃未保存对局。
- 修复场地导览状态仍沿用上一操作步骤而导致只显示文字、不定位高亮区域的问题：导览模式强制按 `layout` 选择当前区域，恢复蓝框、目标区正常亮度与其余区域暗幕。
- 自组牌组筛选收敛为角色、红、绿、蓝四类；行动牌每次拖入一张。
- 已重新打包分享版。
