# 稳定 EXE 交互回归修复

范围仅限 `桌面EXE版/稳定版/鸣潮对决桌面版/app/demo/`，未修改 CMD/HTML 源版本、启动 EXE 或服务器壳。

- 新手教程固定玩家先手，并恢复全局暗化与当前操作目标高亮。
- 开局换牌保留“选择任意张后确认换牌”的可用流程。
- 自定义牌组只展示角色卡、红色卡、绿色卡、蓝色卡四类；行动牌每次拖入为 1 张。
- 弃牌流程恢复可勾选手牌，新增居中选择提示与进度；战斗和追击效果的抽牌统一先播放居中抽牌动画。
- 修复测试卡牌与普通战斗共用的后续结算遗漏：效果登记“抽牌后弃牌”时，抽牌动画后先进入弃牌选择，不再直接交回合。
- 规则口径修正：双方蓝色闪避对撞时仍为无伤害平局，但双方都按“己方胜利”结算各自蓝色卡的【判定】效果。
- 双方同时触发“抽后弃牌”时改为队列结算：玩家选择弃牌后，再由 AI 自动完成自己的弃牌，避免后者覆盖前者。
- 对抗结束不再提前切换回合：先完成伤害、抽牌、弃牌等全部效果；玩家再手动结束本回合，AI 则在效果结束后自动结束自己的回合。
- 双方都有卡牌/角色效果时，统一按“战斗基础伤害 → 对抗发起方全部效果 → 响应方全部效果”顺序结算；卡牌效果的额外伤害属于后半段效果结算。
- 修正左侧对局记录的旧文案：不再在效果结算前显示“直接进入对手回合”。
- 效果弃牌改为专用选择弹窗：在弹窗内勾选手牌并点击“确认弃牌”，不再使用战场右下角的结束回合按钮。
- 抽牌动画结束后立即刷新底部手牌；效果弃牌弹窗将“确认弃牌”固定在底部可视区域。
