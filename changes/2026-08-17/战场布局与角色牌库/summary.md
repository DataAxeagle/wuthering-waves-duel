# 战场布局与角色牌库

## 已实现

- 双方角色区的名称、生命与护盾统一放到左侧信息列；移除了重复的手牌、协奏、弃牌计数文字。
- 协奏区下方新增“角色牌库”入口，显示对应玩家剩余的真实角色牌库数量。
- 打开角色牌库后，左侧显示全部剩余角色牌预览；点击预览，右侧展示完整卡面与卡牌效果；关闭后返回原对局。
- 中央的牌库和弃牌库向下调整。
- 删除角色区底部行动区展示和左侧频率克制说明。
- 回合状态栏移到战场顶部。
- 删除右上角“重开对局”和本地 AI / 未配置 Key 状态提示；保留主菜单、保存对局和规则。

## 二次布局优化

- 护盾移动到生命值右侧；回合状态条居中到战场顶部。
- 右侧栏固定为上方操作按钮、下方当前选择效果。
- 协奏区与角色牌库压缩为紧凑的 COST / 协奏牌 / 小型角色牌库入口，不再使用横向长条。
- 对局记录中的行动卡名称使用蓝色可悬浮文本；悬浮时显示卡面、数值和效果，移开即消失。
- 对局内点击“主菜单”不再直接离开战场：仅暗化背景并显示居中纵向暂停菜单；提供返回当前对局、保存、规则、图鉴、返回主界面和退出游戏。

## 紧凑布局与背景

- 角色牌库收为 COST 下方的小型牌堆入口；协奏区缩短为紧凑短条。
- 敌方基础信息锚定右上，我方基础信息锚定左下；角色卡行居中展示。
- 我方手牌数量移至左下，移除“单击卡牌查看，再从右侧执行操作”提示。
- 对局背景替换为用户提供的 `输入素材/背景图.png`，运行副本为 `demo/assets/backgrounds/duel-board-user.png`。

## 边界

- 保留右侧实际操作按钮，避免影响充能、升级、更换领队、出牌和结束回合。
- 角色牌库仅供查看，不允许直接出牌，也不改变升级规则。
- 对手的角色牌库和弃牌堆不渲染入口；我方弃牌堆可打开与角色牌库相同的预览 / 详情查看器。
