# 首版交付摘要

## 结论

已交付可直接双击运行的本地人机卡牌对战版。主入口为 `demo/index.html`，无需安装依赖或启动服务器。

## 主要交付

- 独立规则引擎：生命、资源、角色、升级、切换、对抗、伤害、护盾、连击、疲劳、手牌上限。
- 可玩 UI：玩家手牌、双方角色、对局记录、规则弹窗、对抗响应窗口、胜负画面。
- 人机 AI：会充能、升级、切换、使用战术、攻击、防守并结束回合。
- 自制首发卡池：6 名角色和 12 种行动卡模板，卡面使用 CSS 占位视觉。
- 矮视口与宽屏自适应。

## 边界

本版核心规则源于官方新手教学视频的可见内容。官方完整卡表和综合规则尚未公开，因此卡牌数值、疲劳和三色克制为首版可玩化定义，已在项目文档中明示。
