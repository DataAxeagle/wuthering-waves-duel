# 多候选角色升级卡选择

## 修复结果

- 修复角色存在多张合法升级卡时，界面自动取第一张、不给玩家选择的问题。
- 只有一个升级候选时仍直接进入弃牌流程；有两个及以上候选时，先展示每张卡的卡面、等级、编号和效果。
- 玩家选定具体升级卡后，弃牌界面再次显示目标编号与效果，再按该卡等级支付弃牌。
- 炽霞 Lv.0 升级时会分别显示 `BP01-026` 与 `SD01-006` 两张 Lv.1，不再自动选取。
- 修复作用于公共升级交互，因此测试场、普通单机和 PVP 均使用同一选择流程；升级结算规则本身未修改。
- 本轮未部署。
