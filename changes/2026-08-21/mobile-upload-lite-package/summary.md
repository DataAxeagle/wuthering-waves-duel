# 手机版上传精简包

## 目标

为受上传体积限制的平台提供独立的手机版运行时 ZIP，不覆盖原始完整安装包、源码备份或 Cloudflare 正式站。

## 策略

- 保留页面、单机规则、PVP 大厅与战场、公开 PVP 配置、60 张卡牌的 WebP 素材，以及菜单/战场/回合转场所需资源。
- 仅从精简包排除未被当前手机版入口使用的历史 `demo/` 目录、旧角色/行动 PNG 与卡图 WebP 的 PNG 备份、开发说明和脚本。
- 原始 `mobile/` 源码保持不变，PNG 备份继续留在本地源码中。

## 结果

- 完整包：约 289.59 MiB。
- 上传精简包：21.29 MiB，减少约 92.6%。
- 精简包共 80 个条目；静态页面共 7 项本地资源引用、卡库共 60 项 WebP 引用，均已在 ZIP 中核验存在。
- 未部署本精简包；现有 Cloudflare 正式站未修改。
