# 手机版双设备 UI、开局与验证修复

## 结果

- 同一套手机版规则和功能代码现在会按设备能力自动选择 UI：手机/平板保留横屏触控布局，电脑浏览器启用独立 `desktop-ui` 三栏布局。
- 自组牌组的界面校验补齐 `boundHero` 专属角色限制；点击开始时冻结本局配置，并在构造失败时恢复菜单和按钮，避免教程页后卡死。
- 选牌区新增“开启新手教学”复选框，默认关闭；正常开始不再额外弹出教程二次选择页。
- 手机端自组牌组、设置、存档、统计、测试场、图鉴等功能页采用安全区内紧凑布局和内部滚动，避免底部按钮被裁切。
- Turnstile 改为官方显式加载流程，旧组件回调通过 epoch 隔离；固定使用手动重试策略，并校验已有 Supabase 会话，401 后可回到验证流程。
- 功能子页打开时隐藏首页音量悬浮按钮，避免遮住右上角内容。
