# 大卡操作弹窗与战斗效果侧栏

## 修改范围

仅修改 HTML 版本 `demo/`，未修改桌面 EXE 版本、规则核心、AI、存档和卡牌数据。

## 交互调整

- 充能、主动进入战斗、追击改为居中大弹窗选牌；确认按钮左侧、取消按钮右侧。
- 升级改为两步大弹窗：先选角色并确认，再选升级弃牌并确认。
- 对手进入战斗时，我方盖牌选择使用居中大卡弹窗；保留不盖牌的原有选项。
- 追击弹窗可“取消追击”，并按原规则结束当前追击阶段。
- 战斗与追击展示动画右侧增加行动卡效果文字说明。
- 教程在新弹窗内高亮选牌区或确认按钮，避免继续指向已隐藏的旧说明框。
- 对抗盖牌选择改为完整卡面网格，超出时纵向滚动，不再裁切半张牌。
- 所有弹窗选牌/选角色流程新增右侧完整效果栏；开局选领队与起手换牌同样适用。
- 对局内更换领队改为弹窗选择、确认后生效；当前领队始终排在三名角色的中间位置。
- 角色牌库与弃牌库左侧缩略卡改为完整显示卡面，列表过长时仅纵向滚动。
- 图鉴类型统一为角色、红、绿、蓝四类；测试场为我方与对手分别提供行动牌颜色筛选。
- 弹窗教程高亮改为标题说明或确认按钮，不再框选卡牌滚动区；追击说明阶段同时高亮继续追击与停止追击按钮。
- 回合状态移入顶部正中，与左侧 Logo、右侧主菜单同一行。

## 不变项

战斗判定、卡牌费用、结算、AI 决策、存档结构与其他未涉及功能均保持原样。
