# 移岁迷邪己方行动区判定

## 结论

- 修复移岁迷邪实体卡文本“3张或以上”与引擎正则不一致导致的加伤未触发。
- 行动区只计己方行动区，不计对方盖放或行动区内的卡。
- 当前追击打出的移岁迷邪会先进入己方行动区再判定；己方首轮牌、一次追击和移岁迷邪自身合计 3 张时，伤害正确为 `5 + 3 = 8`。

## 验证

- `node --test .\\tests\\game.test.cjs`：30 / 30 通过。
- `node --test .\\tests\\card-library.test.cjs`：3 / 3 通过。
