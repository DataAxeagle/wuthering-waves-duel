# 移动端设置页可见性修复

## 目标

移除无效的“屏幕适配”档位，避免在横屏小高度下将设置页底部操作裁切；界面缩放仅作为用户偏好，不再承担可见性兜底。

## 修改范围

- `mobile/index.html`：移除屏幕档位选择，保留界面大小控制并更新说明。
- `mobile/game.js`：删除屏幕档位状态、存储、事件和视口匹配逻辑。
- `mobile/styles.css`：移除档位专用样式；设置页由固定高度加隐藏溢出改为可见内容与页面滚动；弹层增加可滚动兜底；紧凑横屏压缩非功能留白。
- `rules/项目协作规则.md`：新增横屏功能可见性长期约束。
