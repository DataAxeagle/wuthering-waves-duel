# 移动端战斗缩放布局修复

## 目标

修复手机横屏选择“紧凑 88%”后，右侧操作栏、主菜单入口与底部手牌说明区被挤出真实视口的问题。

## 修改范围

- `mobile/game.js`：紧凑横屏不再只依赖会受 CSS `zoom` 影响的媒体查询，改为根据真实 `visualViewport` 尺寸决定是否保持 `compact-landscape` 布局。
- `mobile/game.js`：缩放宽度补偿从百分比改为基于实时可视宽度的像素值。
- `mobile/styles.css`：右侧操作栏允许纵向滚动，避免未来控件增长时被裁切。

- 右侧“进入战斗”“结束回合”和顶部“主菜单”按钮完整在可视区域内。
- 紧凑横屏类保持启用，右侧栏纵向溢出时可滚动。
