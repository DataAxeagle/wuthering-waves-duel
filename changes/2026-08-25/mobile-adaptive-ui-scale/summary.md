# 手机版与平板界面缩放

## 目标

让用户能在设置内真正调整游戏界面大小，并为 iPad/安卓平板提供独立的横屏布局默认值；完整包和精简包保持同一功能。

## 变更

- 设置页新增 82%–120% 的界面大小滑动条，以及 88%、100%、112% 三个预设和“恢复设备推荐”按钮。
- 缩放值仅保存到当前浏览器；手机默认 100%，平板默认 108%。
- 通过触控能力、短边尺寸和 iPadOS 桌面 UA 识别平板；平板横屏采用战场与操作栏并列的布局，而不是简单放大手机界面。
- 缩放使用 `zoom` 连同布局和触控命中区一起变化；100% 时不启用缩放上下文，避免影响既有页面定位。
- 紧凑横屏设置页允许纵向滚动，确保新增控件可到达。
- 首页和 PVP 入口资源版本统一更新为 `20260825-0115`，避免旧缓存混用。
