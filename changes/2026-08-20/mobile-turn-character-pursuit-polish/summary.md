# 手机版回合、角色触发与追击提示优化

## 结果

- 女漂泊者 Lv.2 改为在己方回合开始时先抽 1 张，再进行本回合常规抽牌；对应触发事件会进入动画流程。
- 新回合展示顺序统一为：回合切换底图 → 角色效果弹窗 → 角色技能抽牌 → 本回合常规抽牌。
- 角色卡的回合开始、回合结束、对抗、判定、连击增伤和专属领队技增伤均携带角色触发弹窗事件，弹窗先于后续伤害/抽牌展示。
- 双方真正切换回合时直接使用用户分别提供的两张透明 PNG：我方回合使用第二张，对方回合使用第一张；只做响应式缩放和淡入淡出，不遮罩、不叠字、不重绘、不调色，并适配 844 × 390 手机横屏。
- 每次追击结算后都会重新检查手牌与费用：只要仍有满足条件的红牌，就继续高亮“继续红色连击”；仅在没有合法红牌时高亮“停止追击”；离开追击阶段后蓝框自动移除。
- 修复追击教学中“停止追击”误显示为“结束回合”并被遮罩压暗的问题：追击阶段文案不再受临时动画锁影响，停止按钮在教学遮罩中始终可见。
- 首页移除“全屏游玩”入口及 Fullscreen API 逻辑；电脑 844×390 预览首页复用真机紧凑布局，避免顶部眉题被画框裁切。

## 边界

- 本轮未部署 Cloudflare、未部署 Supabase、未生成或更新手机版 ZIP。
- 未修改卡组规则、伤害数值、费用规则、AI 决策、PVP 房间逻辑或其他页面功能。
