# 鸣潮对决卡组分类库

本目录是游戏的卡牌唯一来源。catalog.json 为人工可读清单，catalog.js 同时供浏览器与规则引擎加载。

- 来源：卡牌素材 下的 49 张讲解截图。
- 去重：以原文件 SHA-256 复核；没有完全相同的重复文件。
- 卡面：每张均由原讲解图统一裁出（x=207, y=358, 765×1072）。
- 水印：原图存在 SAMPLE，作为来源标识完整保留，未作去除或遮盖。
- 分类：角色牌、红色攻击、蓝色闪避、绿色功能、领队技、变奏技、共鸣技。

游戏中的后续组牌应读取 catalog.js，不要再引用 demo/assets/actions 或 demo/assets/heroes 的 AI 生成图。
