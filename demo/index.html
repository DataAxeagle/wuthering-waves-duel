HOW TO PLAY

回响对决规则

01 // 胜负

双方 20 点生命，将对手降至 0 即胜利。

02 // 准备

抛硬币获胜方选择先手或后手；双方各抽 5 张、可各换牌一次，再同时翻开角色。

03 // 抽牌

先手首回合抽 1 张；此后每个回合的玩家默认抽 2 张。

04 // 主要

充能、升级、更换领队每回合各可做一次，彼此独立，也都可以不做。

05 // 战斗

可以跳过；进入时双方各盖 1 张手牌，同时翻开并按三类牌克制结算。

06 // 升级

选择任意角色，展示角色卡组中同名、同等级或高 1 级的角色卡；弃置与展示等级相同数量的手牌后叠放。

本作为非商业同人规则原型；卡池和数值为本地版自制平衡内容。
