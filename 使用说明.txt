鸣潮：对决桌面版

【启动】

双击「启动鸣潮对决.exe」。无需打开 CMD，也无需另行安装 Node.js。
请始终保留 app 文件夹与 EXE 在同一目录；移动、备份或分享时复制整个「鸣潮对决桌面版」文件夹，不要只复制 EXE。

启动器会在后台使用包内 Node 服务，并优先以 Microsoft Edge 或 Google Chrome 的无地址栏应用窗口显示游戏；若两者都不可用，则调用系统默认浏览器。浏览器窗口关闭后，本地服务会自动停止。

【数据保存与 AI 设置】

玩家名称、战绩、局内存档和自组卡组保存在当前 Windows 用户的资料目录：
%LOCALAPPDATA%\WutheringWavesDuel\player-profile.json

游戏更新、替换或移动本游戏包不会清空上述资料。首次从较旧版本更新后，请完整启动一次新版；浏览器旧本地存储中的自组卡组会同步到 Windows 用户资料，之后即使端口变化也会自动恢复。

DeepSeek API Key 可在游戏内“设置”填写或清除。Key 仅使用当前 Windows 用户的 DPAPI 加密保存于用户资料目录，不会写入游戏包、AI 决策记录或浏览器战绩数据；请勿手动复制、编辑或分享该加密文件。

每局 AI 的规划、盖牌和追击选择会写入同级「AI决策记录」文件夹。它只包含公开局面、合法选项和 AI 最终选择，不记录 API Key。更新游戏时请保留该文件夹；详情见其中的「使用说明.md」。

【更新与备份】

1. 先关闭游戏窗口，等待旧服务退出。
2. 完整解压新版包；推荐直接使用新文件夹，或以新版 EXE 与 app 文件夹覆盖旧同名内容。
3. 覆盖前如需保留 AI 决策历史，请先备份同级「AI决策记录」文件夹；不要删除 Windows 用户资料目录。
4. 如需完整备份个人进度，请在退出游戏后备份整个「鸣潮对决桌面版」文件夹，并另行备份 %LOCALAPPDATA%\WutheringWavesDuel\player-profile.json。

【显示与排查】

界面会适配窗口大小；可按 Ctrl + 鼠标滚轮调整缩放，按 Ctrl+0 恢复默认比例。
若启动提示游戏文件不完整，请确认 app\runtime\node.exe 和 app\server.js 仍在包内，且 EXE 没有被单独移动。若无法打开窗口，请安装或启用 Edge、Chrome，或为 HTTP 链接设置默认浏览器。
