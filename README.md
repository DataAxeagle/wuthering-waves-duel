# 鸣潮：对决（本地版）

一个零依赖、可在浏览器中运行的非商业同人卡牌对战原型。选择三名角色与领队，在红、绿、蓝三色克制与追击机制中，与本地规则 AI 或 DeepSeek AI 对局。

> 本项目是学习与原型验证用途的非商业同人作品，与库洛游戏及《鸣潮》官方没有隶属、认可或合作关系。请勿将其表述为官方产品，或用于未经授权的商业分发。

## 下载游戏包

推荐从本仓库的 [Releases](../../releases) 下载最新 Windows ZIP：完整解压后双击 `启动游戏.cmd` 即可。分享包内置便携 Node 运行时和 `LICENSE`，不需要额外安装 Node.js。

首次启动时可填写 DeepSeek API Key 使用云端 AI，也可选择跳过而使用离线规则 AI。玩家名称、战绩、局内存档和 API 配置均保存在当前 Windows 用户数据目录；更新或替换分享包不会覆盖既有存档。

启动器优先使用 `http://127.0.0.1:4173`。若旧游戏服务仍占用该端口，会自动改用 4174–4193 的可用端口并在 CMD 中打印实际地址；浏览器未自动打开时，请复制 CMD 显示的地址访问。游戏内选择“退出游戏”或关闭最后一个游戏标签页后，本地服务会自动关闭。

## 从源码开始

要求 Node.js 20+：

```powershell
git clone https://github.com/DataAxeagle/wuthering-waves-duel.git
cd wuthering-waves-duel
node --test .\tests\game.test.cjs
```

不使用云端 AI 时，直接双击 `demo/index.html` 即可离线游玩。

## 开始游戏

### 双击启动（推荐）

双击项目根目录的 `启动游戏.cmd` 即可开始游戏；未配置 API Key 时自动使用本地规则 AI。需要 DeepSeek AI 时，先双击 `配置AI.cmd` 完成配置，再启动游戏。Key 仅保存于当前 Windows 用户的凭据管理器，不会进入仓库、分享包或 Git 提交。
### DeepSeek AI 模式

API Key 只放在当前 PowerShell 进程的环境变量中，不要写进 HTML、JavaScript 或提交到项目：

```powershell
$env:DEEPSEEK_API_KEY="你的 DeepSeek API Key"
.\run-deepseek-game.ps1
```

然后打开 `http://127.0.0.1:4173`。页面右上角显示 `DeepSeek · deepseek-v4-flash` 即表示已接通。

如需临时切换模型：

```powershell
$env:DEEPSEEK_MODEL="deepseek-v4-pro"
.\run-deepseek-game.ps1
```

### 无 API 模式

仍可直接双击 `demo/index.html`，此时自动使用本地规则 AI，不会请求网络。

进入游戏后，查看自己的 3 名角色并选择领队，确认后双方同时翻开。

## 主菜单、难度与战绩

- 打开游戏先进入视频封面主菜单；选择初级、中级或高级 AI 后，点击“开始游戏”才会进入选领队与对局流程。右上角可开启或关闭封面视频原声。
- 主菜单提供加载游戏、设置、数据统计、卡牌测试场和卡牌图鉴；正式对局未结束时会额外显示“返回当前对局”。
- 卡牌图鉴支持按角色牌、红色攻击、绿色功能、蓝色闪避、领队技、变奏技和共鸣技筛选，并显示独立卡面、编号、数值、专属领队与完整效果。
- 选择“进入新手指引”时，教学局固定由玩家先手，保证充能、升级、更换领队与战斗教学按同一顺序出现。
- 指引中的操作阶段仅聚焦当前按钮或手牌；确认操作后会恢复全局亮度，完整播放该次充能、升级、切换或战斗结算。动画结束才弹出阶段总结，且总结弹窗会冻结玩家操作与 AI 回合，必须点击“确定”才进入下一步。
- 战斗获胜后若进入我方追击，玩家先阅读战斗总结；确认后系统检查费用足够的红色行动卡。存在可用牌时进入追击指引，可继续连击或主动停止；没有可用红牌时自动停止。追击真正结束后会再冻结并展示追击流程总结。
- 初级 AI 只做基础合法出牌；中级会参考公开领队和三色克制；高级 DeepSeek 会根据公开战场、费用、速度、克制与追击机会选择最优合法动作。本地 AI 降级时也使用对应层级的策略，但不具备模型的完整推理能力。
- 战绩记录总对局、胜场、胜率、造成伤害、受到伤害和打出卡牌。可在主菜单手动清空；不会上传到服务器。

## 操作

- 点击手牌：选中卡牌。
- 充能：将选中手牌放入协奏区，获得 1 点一次性费用；支付后协奏牌进入弃牌区，下回合不恢复。
- 升级：先点击“升级”，再选择场上任意角色，最后选择 1 张手牌弃置；后台角色也能升级。
- 更换领队：选择后台角色；每回合最多一次。
- 主角：主角牌本身没有攻击力或防御力；只有当前领队的被动会强化指定颜色的牌，例如红色攻击加攻击、绿色攻击抽牌、蓝色躲避加护盾。
- 进入拼牌：选择一张费用足够的手牌盖放；双方都盖好后才同时翻牌并同时扣费，盖牌阶段不会泄露所用费用。
- 「查看对方手牌」会先以背面展示可选牌；玩家点选并翻看至少一张后，仍需点击“确认查看，继续”才能结束该效果。
- 跳过拼牌并结束：不进入拼牌阶段，直接轮到对手。
- 拼牌结算：红色攻击克绿色攻击、绿色攻击克蓝色躲避、蓝色躲避克红色攻击；同色攻击比速度，速度相同不触发；完全相同的牌直接抵消。攻击牌按攻击力造成伤害；蓝色牌无攻击力，蓝蓝时双方各自触发效果且不伤害。
- 无限追击：红色攻击赢下拼牌后，可继续打出费用足够的红色行动牌；效果提供的【追击 N】只给 N 次红色连击，随时可点击“停止追击”结束回合。

所有玩家和 AI 操作都会依次播放：充能/弃牌移动、升级、领队切换、双方同时翻牌、效果说明、克制判定、红色受击特效、生命扣除以及进入弃牌区。伤害会先播放受击与伤害数字，再正式扣除生命、更新战绩和判定胜负；AI 每项操作之间会停顿。动画播放期间不能插入下一项操作。

## AI 安全边界

- 浏览器永远拿不到 DeepSeek API Key。
- 服务端只向 DeepSeek 提供 AI 自己的手牌和双方公开信息；不会发送玩家隐藏手牌或已盖卡内容。
- DeepSeek 只能从服务端给出的合法动作编号中选择，客户端会再次校验。
- API 超时、余额不足、返回格式错误时，自动降级到本地规则 AI。
- 公网部署时必须把 `server.js` 部署为后端服务，并在托管平台配置服务端环境变量；不能改成前端直连。

## AI 决策审计

- 通过本地启动器运行时，每次 AI 的回合规划、战斗响应和追击选择都会生成一份 Markdown，位置为 `AI决策记录/YYYY-MM-DD/`。
- DeepSeek 记录会保留模型返回的简短决策依据与最终 JSON 选择；本地规则 AI 也会记录对应的合法性/评分依据。
- 记录只包含 AI 自己的手牌与双方公开的角色、生命、费用和手牌数量，以及本次合法操作；不会写入玩家隐藏手牌、盖放牌或 API Key。
- 记录用于复盘可见局面下的决策依据，不包含模型隐藏推理过程。详见 `AI决策记录/README.md`。

## 预设卡组

主菜单可分别选择我方与 AI 的两套 40 张行动牌预设：

- 女漂泊者（预组）：漂泊者（女）、秧秧、炽霞各 Lv.0–2；含砰砰·普攻与砰砰·闪避反击。
- 男漂泊者（预组）：漂泊者（男）、今汐、散华各 Lv.0–2。

红色与绿色行动牌的两个数字按“速度、攻击”读取；蓝色行动牌只有“攻击”数值。

## 2026-08-15 官方规则更新

当前版本以官方新手指南为准：抛硬币获胜方选择先后手、双方可各换牌一次、行动卡组抽空时洗回弃牌区、角色升级按展示角色卡等级弃牌；对抗与每张追击行动卡结算后立即送入弃牌堆。红色获胜可无限连击；行动卡或效果提供的【追击N】只给 N 次追击，连击只能使用红色行动卡且对方不能响应。相同颜色的红/绿速度相同由回合方胜利；蓝蓝平局；胜者按行动卡伤害造成伤害。
