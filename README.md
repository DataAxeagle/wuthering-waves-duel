# 鸣潮：对决 v1.0.0

一个本地运行的非商业同人卡牌对战原型。选择三名角色并确定领队，在红、绿、蓝三色对抗、费用、升级与追击规则下，对战本地规则 AI 或 DeepSeek AI。

> 本项目仅用于学习与玩法原型验证，与库洛游戏及《鸣潮》官方没有隶属、认可或合作关系。请勿作为官方产品或用于未经授权的商业分发。

## 下载与启动

从 [v1.0.0 下载页](https://github.com/DataAxeagle/wuthering-waves-duel/releases/tag/v1.0.0) 下载所需版本，完整解压后运行：

- Windows EXE：`Wuthering-Waves-Duel-Windows-EXE-v1.0.0.zip`，双击 `启动鸣潮对决.exe`；不要只复制单个 EXE。
- HTML 分享版：`Wuthering-Waves-Duel-HTML-v1.0.0.zip`，双击 `启动游戏.cmd`；离线规则 AI 也可直接打开 `app/demo/index.html`。

- 分享包内置 Node 运行时，不需要额外安装 Node.js。
- 未配置 API 时使用本地规则 AI；需要 DeepSeek AI 时，先双击 `配置AI.cmd`。
- 启动器优先使用 `http://127.0.0.1:4173`；旧服务占用端口时会自动改用 4174–4193 的可用端口，并在 CMD 中打印实际地址。
- 在游戏内选择“退出游戏”或关闭最后一个游戏标签页后，本地服务会自动关闭。

玩家名称、战绩、局内存档和自组卡组保存在当前 Windows 用户资料中；API Key 单独保存在 Windows 凭据管理器。更新或覆盖分享包不会清空这些资料。

## v1.0.0 大版本更新

- **卡库扩充至 123 张**：加入新行动卡和角色卡，同步相关效果、速度与攻击数值修正。
- **异画选择扩充**：新增普通/金色异画选项；同编号异画共享卡牌身份和组卡数量限制。
- **组卡流程升级**：点击卡牌，左侧查看完整卡面、右侧查看效果；选择数量后确认加入，保留拖拽加牌。角色牌同编号限 1 张，行动牌每种限 3 张；实时提示角色牌与行动牌数量，行动牌需正好 40 张。
- **筛选更清晰**：支持按卡牌类型、所属角色及行动颜色筛选。
- **新卡效果与动画接入**：覆盖效果选牌、免费升级、判定前切换领队、公开抽牌、区域移动和伤害后的追加效果。
- **行动卡背统一更新**：行动牌库、盖牌与抽牌动画使用新版图案；角色卡背保持原样。
- **桌面与手机内容同步**：HTML、EXE 同步最新卡牌和必要功能，保留桌面布局、AI、启动方式及原有用户资料；在线游玩提供腾讯云与 Bilibili 入口。

本次发布包已完成语法、资源完整性与哈希核对；未完成实机及完整对局回归。角色构筑沿用当前规则：3–15 张角色牌，恰好 3 种角色且各包含 Lv.0。

## 游戏功能

- 视频封面主菜单、难度选择、新手指引、局内暂停菜单、对局保存/加载和数据统计。
- 卡牌图鉴：可按角色牌、红色攻击、绿色功能、蓝色闪避、领队技、变奏技、共鸣技筛选，并查看独立卡面、数值与效果。
- 卡牌测试场：指定双方测试牌与领队，快速验证卡牌效果；测试局不计入常规战绩。
- 对抗流程：双方盖牌、同时翻牌、费用支付、克制/速度判定、效果展示、伤害与弃牌动画。
- 红色或绿色攻击胜出后，可在费用足够时继续使用同色攻击牌追击；卡牌文字另有规定时按效果结算。
- 所有伤害路径均按“伤害动画 → 实际扣血 → 更新统计/胜负”结算。

若屏幕尺寸或浏览器缩放造成 UI 拥挤，可按住 Ctrl 并滚动鼠标滚轮，建议在 80%–125% 范围内调整。

## 规则摘要

- 抛硬币决定先后手；双方起手 5 张并各选 3 名角色，确认后同时翻开。
- 先手首回合抽 1 张，之后每回合抽 2 张。
- 充能、升级、切换领队每回合各至多一次，均可跳过。
- 协奏区每张牌提供 1 点一次性费用；支付后该牌进入弃牌区，不会恢复。
- 红克绿、绿克蓝、蓝克红；同色攻击牌按速度判定，蓝蓝双方各自结算效果但不造成攻击伤害。

## 从源码运行

要求 Node.js 20+：

```powershell
git clone https://github.com/DataAxeagle/wuthering-waves-duel.git
cd wuthering-waves-duel
node --test .\tests\game.test.cjs
node --test .\tests\card-library.test.cjs
```

离线规则 AI 可直接打开 `demo/index.html`。需要 DeepSeek AI 时，运行 `启动游戏.cmd` 或在 PowerShell 设置 `DEEPSEEK_API_KEY` 后执行 `run-deepseek-game.ps1`。

## 本地目录与发布包

- `assets/`：原始卡面和输入素材；不参与运行时加载，也不提交到公开仓库。
- `packaging/desktop-exe/`：桌面 EXE 的封装开发项目；请勿将其与稳定交付包混用。
- `releases/stable-desktop/`：已验证稳定桌面版。
- `releases/share-packages/desktop/builds/`：桌面分享包；运行 `打包分享版.ps1` 会在此生成带时间戳的目录和 ZIP。
- `releases/share-packages/mobile/builds/` 与 `releases/share-packages/mobile/archive/`：手机版构建包和按日期归档副本。
- `archives/`：备份与修改前快照，只用于回溯，不是可运行的当前版本。
- `output/`：临时测试和一次性导出，不保存对外安装包。

## AI 与数据边界

- 服务端仅向 DeepSeek 发送 AI 自己的手牌与双方公开局面；不会发送玩家隐藏手牌或已盖卡内容。
- 模型只能从服务端提供的合法动作中选择；异常、超时或余额不足时会回退到本地规则 AI。
- 联网模式会按对局写入 `AI决策记录/` Markdown；不记录 API Key、玩家隐藏手牌或模型隐藏推理。
- 公网部署必须把 `server.js` 作为后端服务运行并配置服务端环境变量，不能把 API Key 写入前端。
