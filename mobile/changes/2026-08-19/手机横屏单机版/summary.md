# 手机横屏单机版

将浏览器单机模式改造成 iPhone 15 Pro 横屏优先的触屏交付：竖屏提示旋转；横屏把战场、右侧操作与底部可横滑手牌固定在同一屏内；保留真实视频封面并提供海报回退。

Cloudflare Pages 只发布 `demo/` 静态目录，单机使用本地规则 AI。已将 69.2MiB 原始封面转为 3.58MiB、854×480 H.264/AAC 的 `menu-mobile.mp4`，原片移入忽略的输入素材目录；Pages 静态模式跳过所有 `/api` 请求并隐藏 DeepSeek 配置。生产入口为 `https://wuthering-waves-duel-mobile.pages.dev`。DeepSeek 代理、Windows 用户资料同步和联机功能均不进入本次公开静态部署。

后续 UI 修复加入 `preview.html`：电脑中嵌入真实的 844×390 iPhone 15 Pro 横屏运行时，主菜单二级页、准备阶段和战场使用同一套横屏约束；不再以桌面页等比缩小来假装手机预览。

战场第二轮按手机可读性收束：底部手牌提升至 74×102px、场上角色牌提升至 66×88px（领队 72×94px）；双方左侧只显示手牌数、COST 与 HP，协奏区不再铺开已充能卡。双方的牌库、角色牌库、弃牌堆固定在右上/右下；右侧仅保留“进入战斗”和“结束回合”。点按手牌会先弹出“选择充能”，再打开“确认充能”框；点按领队可进入“更换领队”并在弹窗中选择、确认新领队，升级也移入角色点按菜单而不丢失规则入口。

后续交互调整为更贴近触屏：点按手牌只会选中卡牌，并在该卡旁显示小闪电充能图标；点图标立即执行充能，不再出现二次确认框。新手流程和战场导览同步移除了已隐藏的右侧“充能 / 升级 / 换领队”按钮说明：升级从角色点按菜单进入，换领队从当前领队点按菜单进入，右侧只讲解战斗与结束回合。

准备阶段改为左侧选中卡大图、右侧上方角色牌与下方起始手牌的双栏结构；点击角色或起始手牌都会同步更新大图。先后手选择置顶，重复文字隐藏，两个确认按钮缩小并固定于底部。

战场进一步将回合流程独立置于顶部；非战斗状态隐藏中央旧对抗组件，只在实际盖牌对抗时显示。角色与手牌均增大，手牌固定左对齐；原右侧“当前选择”说明区移入手牌右侧，点任意手牌或场上角色可在该区域阅读名称、费用、技能与效果说明。

第三轮交互与展示调整：准备页改为左侧角色、下方起始手牌，右侧大卡图与文字效果并列；选择先后手会保留并高亮“已选择”状态。回合条移动到顶栏；升级从角色菜单直接进入弃牌代价选择，不会重复选角色；领队在场上和动画中均固定为中间位。进入战斗的我方选牌改为全屏大弹窗横滑选择后确认打出；对方响应/连击选择同样使用大弹窗。翻牌、胜负展示按横屏高度缩放以完整显示卡图；角色牌库压缩文字并让左侧可滚、右侧完整静态展示。

第四轮阅读优化：准备页锁定为左上角色、左下功能牌（横滑），右侧保留大图和文字；战场状态栏整体右移并加入圆形头像，设置中可上传图片并裁切保存至当前浏览器。删除“当前选择”标题，右侧选中说明居中且优先单屏展示。角色牌库左栏缩略图使用完整 contain 显示；进入战斗和升级弃牌均使用“左侧大卡横滑选择、右侧效果说明”的全屏弹窗。翻牌区去掉卡面外框，玩家名上移，卡面右侧直接呈现本次卡牌效果。

第五轮修复：准备页不再让外层 grid 定位穿透，明确强制左上角色区、左下功能牌横滑区；同时翻牌阶段的支付提示和胜负判定收进同一个弹窗底部结果栏，不再用 fixed 浮层覆盖卡面或右侧效果说明。

Cloudflare 上线：`mobile/` 发布到 Pages 项目 `wuthering-waves-duel-mobile`，项目根目录 `functions/api/` 提供同源 Pages Functions。网页中输入的 DeepSeek Key 仅保留在当前页面内存，随每次 AI 决策经 HTTPS 发送到 Function 并立即转发给 DeepSeek；Functions 不写 Key、对局数据或决策日志。生产 `/api/status`、`/api/configure-ai` 已验证可用；真实 DeepSeek 调用需由玩家自行填入有效 Key 后进行。

未发布的本地下一版：主菜单增加“全屏游玩”入口和 iOS PWA standalone 元数据；暂停菜单缩小到横屏可视区。右下说明去边框上移，叠放角色的 Lv.0–2 技能横向并列；HP、上限、护盾同排。翻牌无牌时仅写“没有牌”；胜负展示重排为左侧完整卡面与效果、右侧胜负结论。

继续未发布的本地调整：组牌卡库改为左侧两列纵向滚动、右侧固定预览；选择卡后出现加号，点击后按数量弹窗加入，牌组内的牌点击后按数量弹窗移除。测试场改为敌我双方各自红/绿/蓝牌色筛选后选卡；图鉴缩为角色、红、绿、蓝四类并在横屏单屏展示。充能标记锚定到所选手牌右上角；领队交换候选牌放大；翻牌与胜负展示的卡牌右侧补齐 COST、速度、攻击和卡牌效果，单卡动画使用完整 contain 卡面。

参考 `https://mc.sldark.com/` 的无账号房间入口、六位房间码与观战信息架构，联机作为后续独立服务端阶段，不阻塞单机版。
